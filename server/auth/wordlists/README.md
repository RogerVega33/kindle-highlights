# Diccionario de recuperación

Adaptación de **EFF Short Wordlist #1**, de Electronic Frontier Foundation (EFF): 1.295 palabras de hasta cinco letras.

- [Lista original](https://www.eff.org/files/2016/09/08/eff_short_wordlist_1.txt).
- [Descripción de las listas EFF](https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases).
- [Licencia CC BY 4.0 International](https://creativecommons.org/licenses/by/4.0/), según la [política de EFF](https://www.eff.org/copyright).

Se eliminaron los índices de dados y la palabra `yo-yo` para conservar sólo letras ASCII minúsculas y evitar ambigüedad con el separador de la frase. Las demás palabras se conservaron. Fecha de obtención registrada: 22 de septiembre de 2026.
